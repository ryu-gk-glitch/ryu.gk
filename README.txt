GKアナライザー(オフライン対応版)

■ 入っているファイル(すべて同じフォルダに置く)
 index.html / manifest.webmanifest / sw.js
 icon-180.png / icon-192.png / icon-512.png / icon-maskable-512.png

■ 使い方の流れ
1. このフォルダを、HTTPSで見られる場所に置く(下の「置き場所の例」)
2. スマホ・PCのブラウザで、そのURLを一度開く(この時だけ通信が必要)
3. ホーム画面に追加する
   - iPhone: Safariで開く → 共有ボタン → 「ホーム画面に追加」
   - Android: Chromeで開く → メニュー → 「アプリをインストール」(または「ホーム画面に追加」)
   - PC: Chrome/Edgeのアドレスバー右の「インストール」ボタン
4. 以後は、電波がなくてもホーム画面のアイコンから起動できます

■ 置き場所の例(どれも無料・HTTPS)
- GitHub Pages: リポジトリを作り、このフォルダの中身を置いて、Settings > Pages で公開
- Netlify Drop(app.netlify.com/drop): フォルダをドラッグ&ドロップするだけ
- Cloudflare Pages など
※ file:// で直接開く方法では、オフライン用の仕組み(sw.js)は動きません。

■ 注意
- データは、その端末のそのブラウザの中にだけ保存されます。
  端末やブラウザが変わると見えません。ブラウザのデータを消すと消えます。
- バックアップ: ホーム下部の「データをコピー(JSON)」→ メモなどに貼り付けて保管
- 復元・引っ越し: ホーム下部の「データを読み込む」に貼り付け(今あるデータに追加されます)
- PDF保存は、ブラウザの印刷機能を使います。「🖨 PDF保存(印刷)」を押して、
  印刷画面で「PDFに保存」を選んでください(iPhoneは共有→「ファイル」に保存)。
- 更新するとき: index.html を差し替え、sw.js の先頭の CACHE の番号(現在 gk-analyzer-v2 → v3)を上げてください。
  そうしないと、端末が古い版を使い続けることがあります。
